# 中国商品 MOM12 横截面动量策略 — text 架构图与策略说明

> 数据源：38 个中国商品主连（46 个 CSV 剔除 8 个金融期货 IC/IF/IH/IM/T/TS/TF/TL），
> `date,open,high,low,close,volume,hold,settle` 日频，2005-01 起。
> 月末调仓、月频回测；换手成本单边 5bp（压力 20.5bp）；主窗 2006-01~2026-10（238 个月）。

## 一、研究脉络（论文 → 本地证据 → 策略）

```
BP2019 基差动量 (BM = ∏(1+r_first) − ∏(1+r_second))
  │  论文命题：期限结构压力延续 → 做多高 BM
  │
  ├─ Kwon2021  把 12M 拆成 BM(5,1)近中期 / BM(0,0)当月 / BM(11,6)历史
  ├─ Koijen2018 Carry=(F1−F2)/F2/月数 → 当前斜率对照
  │
  ▼ 本地复现（38 商品主连，slope代理=换月跳空采样，已验证未复权拼接）
  ├─ BM5→Δslope IC = −0.235 (t=−13.05)  🔴 中国市场反号
  ├─ slope 均值回复 IC = −0.554 (t=−40.6)
  └─ BM5 残差→下月收益 −0.198（控制Carry/MOM后）
  │
  ▼ 结论：BM 在中国不是收益信号，是反转风险因子
  │
  ▼ 策略化：MOM12 横截面动量做主腿（TSMOM 原方向保留），
            BM/slope 信息只以「连续正交化」形态注入（C 变体）
```

三个独立数据集收敛：合同级 47 商品 / 六 ETF / 主连 38 商品 —— 中国商品横截面 12 月动量
远强于一切期限结构类因子。

## 二、最终架构 v2（text 图）

```
L0 数据层   38 商品主连 → 月度面板（MOM12 / ds6 / vol12 / slope）
     │
L1 信号层   MOM12 = 过去12个月主连收益（剔换月跳空口径）复利 − 1
            ├─ 多窗化(MOM3/6/12)已证伪：12M 即正确尺度
            └─ 可选：⊥Δslope6 截面残差化（C 变体，BM 反号信息唯一有效入口）
     │
L2 分割层   1/3 硬切（Top/Bottom thirds） ｜ 中位数分割（E4，回撤优先）
     │
L3 权重层   腿内等权 ｜ 腿内逆波动（1/vol12 归一，D2）
     │
L4 风控层   无 ｜ 波控 m_t = min(1.5, 12%/过去12月净波动)（B/D4）
     │
L5 执行层   月末再平衡；换手=全截面|Δw|绝对和；多空各名义1.0（净敞口0）
```

## 三、家族 20 变体总账（全部预注册冻结、单遍执行）

| run | 变体 | 结论 |
|---|---|---|
| paper44 | S1 纯MOM12 HL / S2 long-only / S3 BM反转剔除 | S1 全过门槛；S3 无增量 |
| arch_v2 | A 多窗混合 / B 波控 / C 残差动量 | A/B 否；C PASS（2011 −0.5% vs S1 −8.4%） |
| arch_v3 | D1 斜率缩放 / D2 逆波动 / D3 跳月 / D4 C×B | **D2 新最优**；D4 DOMINATES；D3 证伪 |
| arch_v4 | E1 mom1 / E2 slope / E3 绝对动量门 / E4 中位分割 | E1-E3 全否；E4 PASS（实现退化已披露） |
| arch_v5 | F1=C+中位切 / F2=D4+中位切 | F1 风险形态过但均值显著更低(t=−2.88)；F2 REJECT |

**总规律**：往 MOM12 腿内加第二信号全部失败（E1/E2/E3/A 四次）；
有效改良只有换权重形态（逆波动）、换分割宽度（中位分割）、信号层正交化（残差）。
且 F1 证明中位分割与残差动量**不兼容**（破坏 2011 崩溃保护：C −0.5% → F1 −7.3%）。
