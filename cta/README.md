# cta/ — 中国商品 MOM12 横截面动量（38 主连，月频多空）

> 38 个中国商品主连（46 个 CSV 剔除 8 个金融期货 IC/IF/IH/IM/T/TS/TF/TL），
> 日频 `date,open,high,low,close,volume,hold,settle`，2005-01 起。
> 月末调仓、月频回测；换手成本单边 5bp（压力 20.5bp）；主窗 2006-01~2026-10（238 个月）。
> ⚠️ 全部为历史研究（`VIEWED_HISTORY_NOT_OOS`），主连 PNL 为滚仓近似，未建模
> 保证金/涨跌停/流动性/容量，不是实盘收益，也不代表未来表现。

## 研究脉络（论文 → 本地证据 → 策略）

```
BP2019 基差动量 (BM = ∏(1+r_first) − ∏(1+r_second))
  │  论文命题：期限结构压力延续 → 做多高 BM
  ├─ Kwon2021  把 12M 拆成 BM(5,1)近中期 / BM(0,0)当月 / BM(11,6)历史
  ├─ Koijen2018 Carry=(F1−F2)/F2/月数 → 当前斜率对照
  │
  ▼ 本地复现（38 商品主连，slope代理=换月跳空采样，已验证未复权拼接）
  ├─ BM5→Δslope IC = −0.235 (t=−13.05)  🔴 中国市场反号
  ├─ slope 均值回复 IC = −0.554 (t=−40.6)
  └─ BM5 残差→下月收益 −0.198（控制Carry/MOM后）
  │
  ▼ 结论：BM 在中国不是收益信号，是反转风险因子
  ▼ 策略化：MOM12 横截面动量做主腿（TSMOM 原方向保留），
            BM/slope 信息只以「连续正交化」形态注入（C 变体）
```

三个独立数据集收敛（合同级 47 商品 / 六 ETF / 主连 38 商品）：中国商品横截面

## 关键回撤与分年特征

- S1 最深回撤 −15.85% @ 2011-04；−8% 以上回撤集中在 2008-2012（旧合约稀疏期）与 2016（供给侧改革反转段）
- D2 在 2011、2016 两个 S1 深坑（−12% 级）下只有 −4~−6%；2011 年转正（+0.9% vs S1 −8.4%）
- C 的收益集中在动量崩溃年：2011 −0.5%、2007 +46.1%（vs S1 +27.4%）、2021 +46.1%（vs +34.9%）
- 分年（S1）：21 年仅 3 年为负 —— 2006 −3.6% / 2011 −8.4% / 2013 −1.7%；2009 +87%、2025 +60% 为两大贡献年
