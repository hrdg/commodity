# 沥青 BU 双低择时策略

本目录复算沥青期货的“裂解价差 + BU-FU 价差”双低择时。策略只做多 BU，不加杠杆；信号在收盘生成，下一交易日持有，单边成本 3bp。

当前状态：**研究候选**。2015–2021 用于策略开发，2022–2026 作为留出区间检查；留出区间不是预注册样本外，参数也没有做逐年前瞻选择。

## 策略公式

```
裂解价差 = BU_adj − Brent(t−1) × USDCNY × 7.35
BU-FU 价差 = BU_adj − FU_adj

裂解 z = rolling_robust_z(裂解价差, 252)
价差 z = rolling_robust_z(BU-FU 价差, 252)

目标仓位 = 1，当且仅当 裂解 z < 0 且 价差 z < 0；否则为 0
```

- `BU_adj`、`FU_adj`：由主连日收益重建的连续价格。BU/FU 单日收益截断在 ±3.5%，用于压低换月跳空。
- `Brent(t−1)`：Brent 现货前一日值，按 BU 交易日对齐后前向填充。
- `USDCNY`：美元兑人民币，按 BU 交易日对齐后前向填充。
- robust z 使用 252 日滚动中位数和 MAD，最少 126 个观测。
- 手续费按仓位变化收取，单边 3bp。

7.35 是 Brent 美元/桶换算为人民币元/吨的桶吨系数。该定义是成本代理，不是逐炼厂加工利润。

## 历史绩效

回测区间 2015-01-05 至 2026-10-28；复利、1 倍名义本金、只做多。

| 区间 | 策略年化 | 夏普 | 卡玛 | 最大回撤 | 平均仓位 | 买入持有年化/夏普/最大回撤 |
|---|---:|---:|---:|---:|---:|---:|
| 2015–2021 开发 | 6.77% | 0.492 | 0.257 | −26.4% | 31.9% | — |
| **2022–2026 留出** | **12.58%** | **0.893** | **0.975** | **−12.9%** | **33.2%** | 12.35% / 0.631 / −31.1% |
| 2015–2026 全期 | 9.10% | 0.646 | 0.344 | −26.4% | 32.4% | 4.82% / 0.318 / −51.4% |

留出区间的年化与买入持有接近，差异主要在波动、夏普和回撤。主策略平均只持有约三分之一时间，不能在收益上理解成对买入持有的稳定增强。

### 单因子与组合

所有结果使用同一复权口径、252 日窗口和 0 阈值，仅改变信号。

| 信号 | 全期年化/夏普/卡玛 | 留出年化/夏普/卡玛 | 平均仓位 |
|---|---:|---:|---:|
| 裂解低位 | 11.91% / 0.715 / 0.494 | 11.30% / 0.725 / 0.480 | 49.5% |
| BU-FU 低位 | 6.72% / 0.446 / 0.134 | 14.05% / 0.859 / 0.963 | 52.0% |
| **双低 AND** | **9.10% / 0.646 / 0.344** | **12.58% / 0.893 / 0.975** | **32.4%** |
| 双低 score（各 0.5） | 9.60% / 0.629 / 0.310 | 12.92% / 0.853 / 0.722 | 50.7% |

AND 组合降低了仓位和回撤，但全期卡玛低于裂解单因子。它是风险约束型配置，不是每个区间都最优的信号。

### 稳健性

- 单边费用 0/3/5/10/20bp：全期年化 9.4%/9.1%/8.9%/8.3%/7.2%；留出 12.9%/12.6%/12.3%/11.8%/10.6%，未因成本翻转。
- 信号延迟 1/2/3 个交易日：全期年化 9.1%/11.1%/9.0%；留出 12.6%/12.6%/8.5%，结果对执行时点敏感。
- 252/504 日窗口和 0/−0.25/+0.25 阈值均为正收益；126 日窗口明显变弱。
- 直接用未复权主连水平计算裂解和价差会得到更高结果（全期 13.2%/0.960），但其中包含换月跳空，不能作为正式绩效。

## 运行

```sh
cd 沥青
python strategy.py --output output
python run.py --output output
python -m unittest discover -s tests -v
```

依赖见 `requirements.txt`。`strategy.py` 输出主策略的逐日仓位、指标和净值图；`run.py` 重算单因子与组合表。

## 数据与限制

- 数据来源、日期覆盖和时点处理见 `data/DATA_COVERAGE.md`，文件校验见 `data/SHA256SUMS`。
- 沥青厂库/社会库存、日度基差、开工率、周产量、山东毛利、焦化利润、稀释沥青进口和仓单历史不足，**没有纳入回测**。本策略只验证成本、价差、趋势和季节层，不是系列 26 的完整基本面复现。
- BU0/FU0 是主连行情，复权由截断收益重建，不是逐合约换月账本；换月日、流动性和涨跌停成交限制未逐笔建模。
- 2025 年消费税及政策变化未单独重估。
- 未计冲击成本、保证金占用和展期滑点；3bp 只覆盖手续费近似。
- 历史结果不代表未来，不构成实盘建议。

## 文件

- `strategy.py`：主策略与绩效输出。
- `run.py`：单因子、AND 与 score 组合对照。
- `config.json`：冻结参数。
- `lab.py`：复权、robust z 和回测函数。
- `data/`：BU0、FU0、Brent、USDCNY。
- `output/`：指标、逐日仓位、因子表和净值图。
- `tests/`：策略规则与绩效门槛测试。
- `REPORT.md`：完整假设、证据和裁决。
