# Commodity Strategies

国泰君安期货商品基本面量化系列的可复算研究包。每个品种一个独立目录，包含冻结参数、数据、策略代码、测试和研究说明。

## 目录

### `豆粕/`

系列 26《豆粕基本面与量价择时多因子模型研究》的复现与优化。

- 策略：`sign(0.8 × 优化基本面5 + 0.2 × 优化量价9)`
- 2025–2026 真样本外：17.5% / 1.08 / 0.91（年化/夏普/卡玛）
- 2022–2026 合并：19.9% / 1.01 / 0.68
- 状态：B 级研究候选；只覆盖 7/9 个基本面因子，2016–2021 全国库存与月度生猪总存栏仍缺。

```sh
cd 豆粕
python strategy.py --output output
python -m unittest discover -s tests -v
```

### `铜/`

系列 28《沪铜基本面与量价择时多因子模型研究》的公开宏观子集。

- 策略：`sign(0.5 × 基线宏观4 + 0.5 × 优化宏观4)`
- 2025–2026 真样本外：16.4% / 1.08 / 1.16
- 2022–2026 合并：11.3% / 0.73 / 0.45
- 状态：B 级研究候选；只覆盖 4/14 个宏观/基本面因子，量价 7 因子未纳入。

```sh
cd 铜
python strategy.py --output output
python -m unittest discover -s tests -v
```

## 通用口径

- 单因子映射为 0/1/-1，等权合成；1 倍杠杆、双边万三、t+1 收盘、收益累加。
- 参数选择使用训练/验证/留出：2016–2021 训练、2019–2021 验证、2022–2024 伪样本外、2025–2026 真样本外。
- 所有结果都是历史研究，不构成实盘建议。

## 数据与限制

- 豆粕：M0/RM0/A0/Y0 主连、基差、仓单、港口/原料/豆粕库存、豆菜价差。M0 为不复权主连，已做换月清洁与 ±6% 截断。
- 沪铜：CU0 主连、DXY（UDI 镜像）、VIX、ISM、CFTC 铜净持仓。CU0 为不复权主连。
- 两个品种都不是原文完整复现；具体缺口见各目录的 `data/DATA_COVERAGE.md` 与 `研究说明.md`。
