# 沪铜公开宏观+量价子集：pilot 与修正

- 目的：在系列 28 全文/产业数据未齐前，先用公开数据验证沪铜宏观与量价方向。
- 数据：CU0 2010-01-04..2026-10-20；DXY（UDI 镜像）、VIX、ISM 制造业 PMI；量价 7 因子。
- 规则：0/1/-1 等权，1x，双边万三，t+1 收盘，收益累加。

## 结果（年化/夏普/卡玛）

> 首轮 pilot 的切片指标存在 NaN/索引偏差，已作废；修正后的完整结果以本文“补充数据后的第二轮”为准。首轮的方向结论仍成立：量价 7 因子三段为负。

## 结论

- 公开宏观 3 因子三段为正，是首轮候选；加入 CFTC/基差/库存后，最终推荐宏观 4 的 50/50 混合。
- 量价 7 因子在 CU0 上三段为负，不能采用；需要先做 CU0 复权连续，再判断是数据还是因子定义问题。
- 合计被量价拖累；当前不应把 10 因子等权当候选。
- 原文 28 篇：基本面 33.5%/4.00，全因子 18.1%/1.53；本 pilot 只覆盖 3/14 宏观 + 7 量价，不是复现。

- 基线宏观4 的真 OOS 最强，但 2022–2024 几乎为零。
- 优化宏观4 的伪OOS 最好，但真OOS 只有 0.65。
- **50/50 混合**在三段都为正，验证 1.15、伪OOS 0.51、真OOS 1.08；当前推荐作为铜的平衡候选。

### 宏观+量价合成

- 优化 PV7：2016–2018 0.32，2019–2021 -0.09，2022–2024 -0.09，2025–2026 -0.10。
- 基线 PV7：-0.54/-0.51/-0.15（2016–2024/伪OOS/真OOS）。
- 用基线宏观4 + 优化 PV7 做 overlay：10% 权重把伪OOS 从 0.26 提到 0.42，但真OOS 从 1.48 降到 1.35；50% 权重真OOS 降到 0.70。
- 结论：**量价 overlay 不改善铜的真 OOS**，当前不纳入核心；最多保留 0–10% 作诊断。

### 当前铜候选

**宏观 4 因子的 50/50 混合**（基线等权 z 与 2016–2021 两折优化版各半）：

- 2022–2024：8.0% / 0.51 / 0.32
- 2025–2026：16.4% / 1.08 / 1.16
- 2022–2026：11.3% / 0.73 / 0.45

这不是 28 篇复现：只覆盖 4/14 个宏观因子，且量价 7 因子在铜上不可用。14 因子仍缺 SMM/Wind 的 TC、社会库存、精废价差、铜箔加工费、LME/COMEX 库存。
