# 沪铜公开宏观 50/50 混合策略（系列 28 子集）

本目录是国泰君安期货《因子与指数投资揭秘系列二十八：沪铜基本面与量价择时多因子模型研究》的**公开宏观子集**，不是 14 因子完整复现。当前状态：**B 级研究候选，不可直接实盘**。

## 策略公式

```
最终仓位 = sign(0.5 × 基线宏观4 + 0.5 × 优化宏观4)
```

两边都是 0/1/-1，1 倍杠杆、双边万三、t+1 收盘、收益累加。

## 重要限制

1. 只覆盖 4/14 个宏观/基本面因子；缺 SMM/Wind 的铜精矿 TC、社会库存、基差、精废价差、铜箔加工费、LME/COMEX/SHFE 库存。
2. 量价 7 因子在 CU0 上两段样本外为负，未纳入；原文量价 13.5%/1.32 未复现。
3. CU0 是 Sina 不复权主连，只做 ±6% 截断；未建商业复权连续。
4. 2025–2026 真OOS 只有 432 个交易日、一个市场状态；50/50 权重是诊断选择，不是预注册最优。
5. 原文基本面 33.5%/4.00、全因子 18.1%/1.53；本策略不是这些数字的复现。
