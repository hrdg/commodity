## 2. M1

| 项目 | 设置 |
|---|---|
| 投票数 | 6票，看多票为1，未知票不填补 |
| 持有条件 | 看多票数 `>= 3` |
| 目标仓位 | 条件成立100%，否则0% |
| 决策频率 | 月末 |
| 成交 | 冻结月度信号的 `exec_date`，上金所收盘 |
| 成本 | 主结果10bp，压力20bp |

公式：

\[
v_t\in\{0,1,NA\}^6,\quad
w_t^{M1}=\mathbf 1\left(\sum_{j=1}^{6}\mathbf 1[v_{j,t}=1]\ge3\right).
\]

若未知票使结果无法唯一确定，日频诊断状态保持上一有效raw；月频M1直接使用已冻结
父信号的三个值规则。

## 3. M1 + VOL15

| 项目 | 设置 |
|---|---|
| 波动估计 | SGE收盘日收益的63个交易日样本标准差，年化 `sqrt(252)` |
| 目标波动 | 年化15% |
| 原始缩放 | `15% / 年化实现波动` |
| 边界 | 最低30%中月度仓位，最高100% |
| 执行滞后 | 缩放因子向前收益滞后1个交易日 |
| 最终仓位 | `M1目标 × VOL15缩放` |

公式：

\[
\sigma_t=\operatorname{std}(r_{t-62:t},ddof=1)\sqrt{252},
\]

\[
s_t=\operatorname{clip}\left(\frac{0.15}{\sigma_t},0.3,1\right),
\qquad
w_t^{M1+15}=w_t^{M1}s_{t-1}.
\]

## 4. 时间与账本

```text
月末六票
  -> M1目标
  -> 下一上金所交易日收盘成交
  -> 每日计算63日实现波动
  -> VOL15缩放滞后一日
  -> 仅目标变化时交易
  -> nav = cash + units * close
```

`VOL15` 不改变六票方向，只降低或恢复月度多头的暴露。

## 5. 结论

- M1是收益优先基线；
- M1+VOL15是风险优先影子版本；
- 两者都没有独立样本外；
- 2026-11-20快照下两者目标均为0%。
