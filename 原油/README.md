# 原油 QDII 择时：裂解价差 + 库欣库存 + 溢价分层

标的：**160723 嘉实原油 LOF**（期货型 QDII，底层为海外原油期货 ETF，WTI 为主）。

当前状态：历史研究候选，样本内结果；溢价数据依赖基金 NAV 披露，未做 2027 前瞻验证，不可直接实盘。

审计状态（2026-10-29）：旧结果可复算，但 EIA 数据发布时点、USO 跨市场日历和同收盘成交口径未通过审计，不能认证为无未来数据或干净 OOS。详见 `audit_20261029/REPORT.md`。

## 策略公式

```
基础信号 = max(裂解价差信号, 库欣库存信号)          # 0/1
裂解价差 = (2×汽油×42 + 取暖油×42 − 3×WTI) / 3    # 3-2-1，美元/桶
裂解信号 = 1 if 裂解价差 > 252日滚动中位数
库欣信号 = 1 if 库欣52周均值 > 4周前
溢价 = 收盘价 / 滞后NAV − 1
仓位 = 基础信号 × 溢价权重
溢价权重（滞回）：>10% 空仓；<5% 满仓；5–10% 维持上一状态
```

- 只做多，不加杠杆；收盘决策，下一交易日持有；单边 3bp。
- 裂解数据在美股收盘后可得，下一交易日决策；库欣周五数据、下周三发布，中国 LOF 再延后一天。
- 溢价使用滞后 1 天 NAV，避免用当日未披露净值。

## 重要限制

1. 160723 是期货型 QDII，净值含展期收益、汇率、双重管理费和跟踪偏差；本策略用收盘价交易，溢价层用 NAV 估算。
2. 溢价层在 2020 年 4 月和 2026 年高溢价期贡献很大；样本内结果，可能存在事件依赖。
3. 未纳入申购状态（暂停/限购/恢复）、IOPV、汇率对冲和场内流动性。
4. 原文开源证券的油气策略测试于 WTI 与嘉实原油 LOF；本目录在其双因子上增加溢价层，属于扩展，不是原文逐行复现。
5. 库欣库存使用当前修订后的 EIA 序列，未使用 as-released vintage。
6. 本策略不是实盘建议；历史绩效不代表未来。
