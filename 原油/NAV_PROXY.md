# 更早的 PIT-safe NAV 代理

## 构造

用最近已披露 NAV（lag3）加上**当时已知**的 USO 收益重建 NAV：

```
nav_proxy_t = NAV_{t-3} × (1 + USO_ret_{t-2}) × (1 + USO_ret_{t-1})
premium_proxy_t = close_t / nav_proxy_t − 1
```

USO 收益使用 shift(1)，只使用中国收盘前已知的上一美股 session；NAV 用 t−3，确保在披露截止日内。没有使用中国收盘后的美股 t 日收盘。

## 结果

| 版本 | 全期 年化/夏普/卡玛 | OOS 2022–2026 |
|---|---:|---:|
| 正式：NAV lag3 10/5 | 23.7/1.103/1.068 | 23.7/1.011/1.065 |
| **USO 代理 10/5** | **30.6/1.274/1.377** | **40.5/1.415/1.823** |
| **USO 代理 9/3** | **31.9/1.334/1.435** | **42.9/1.504/1.930** |

代理 NAV 对真实 NAV t−1 的 MAE 为 **1.15%**，收益相关性 0.23；它更接近“更早一天的 NAV”，但不是精确净值。

## 为什么不用 WTI 现货代理

WTI 现货代理的回测更高（10/5 全期 32.5%，OOS 47.7%），但 NAV 误差 **1.71%**、相关性仅 0.17，说明它是另一个更激进的信号，不是可靠的 NAV 估算。不采用。

## 限制

- 代理是估算，不是实际 NAV；在 3%/5%/9% 阈值附近可能翻转。
- USO 有自身展期/费用，和 160723 的 FOF 持仓不完全一致。
- 未纳入 FX（加入 USD/CNY 后 NAV 误差没有改善，回测反而下降）。
- 正式版本仍是 NAV lag3；代理仅作为研究候选，需真实 IOPV/实时净值验证。
