# USO 水平比 NAV 代理（日历与 PIT 修正版）

## 构造

取基准 NAV 的估值日 `d0`（中国交易日 lag3），再用 USO 水平比估计决策日 `t` 的 NAV：

```
nav_proxy_t = NAV_{d0} × USO(last US date < t) / USO(d0)
premium_proxy_t = close_t / nav_proxy_t − 1
```

- `d0` 是决策日前三个中国交易日的 NAV 估值日，满足 T+1 估值、T+2 披露的保守等待。
- 终点使用严格早于中国日期 `t` 的最近一个美国收盘；不使用 China close 之后才发生的同日美国收盘。
- 使用水平比而不是“中国交易日前向填充 USO 日收益”：美股休市不会重复上一笔收益，中国长假期间的美股变动也不会丢失。

## 独立配置

- `config_proxy_10_5.json`：`nav_source=proxy_uso`，10/5 滞回。
- `config_proxy_9_3.json`：`nav_source=proxy_uso`，9/3 滞回。
- `strategy.py --config ...` / `oos_report.py --config ...` / `current_signal.py --config ...` 均可复算。

## 限制

- 代理 NAV 不是基金实际 NAV；USO 有自身展期、费用和持仓差异，阈值附近仍可能翻转。
- EIA 现货/库欣数据的实际历史发布时间未完成逐日核验；基础因子不能宣称完全 PIT。
- 回测仍按收盘决策、下一交易日持有的旧会计口径，容量与开盘成交未认证。
