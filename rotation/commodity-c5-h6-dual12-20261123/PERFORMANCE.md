# Performance Summary

## 口径

- 周频/日频：C5/TIP/DD、原H6、dual12后C5/H6使用日频账本。
- 月频：H6+dual12资本融合使用共同月末收益，先分别扣除各自交易成本，再计50/50跨腿再平衡成本。
- 主成本：5bp；压力成本：20.5bp。
- `CAGR / Sharpe / MDD`。

## 研究裁决

- `C5_RANK2_TIPS_DD`：当前生产基线；
- `H6`：影子候选；
- `dual12后C5/H6`：过滤层否决；
- `H6+dual12后C5/H6`：同载体资本增强否决；
- `H6+宽商品BM5+dual12`：跨载体分散化影子，不能直接上线。
