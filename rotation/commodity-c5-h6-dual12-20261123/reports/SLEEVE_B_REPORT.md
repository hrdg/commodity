# Sleeve B 比较：dual12后C5、dual12后H6与宽商品

日期：2026-11-23
状态：`VIEWED_HISTORY_EXPLORATORY_NOT_OOS`

## 直接回答

**不建议把 Sleeve B 换成 dual12后C5或dual12后H6。**

它们与 H6 sleeve 的月收益相关约 `0.93–0.94`，说明大部分风险来源相同；50/50之后，
Sharpe反而低于单独持有 H6。原先的宽商品 `BM5+dual12` 与 H6 相关仅 `-0.16`，分散化
明显更好。

若仅限于同载体两类，二者排序是：

```text
收益/Sharpe：dual12后H6略优于 dual12后C5
回撤：       dual12后C5略浅
结论：       均不优于单独H6，也不优于宽商品Sleeve B
```

| dual12后H6 | 0.936 |
| 宽商品BM5+dual12 | -0.160 |

同载体组合没有显著降低风险，因为两个组合同样使用六ETF、C5/RANK2和TIP/DD。尤其
`dual12后H6`仍然包含H6本身，主要只差双动量过滤。

## 为什么 dual12后H6 略好于 dual12后C5

- dual12后H6保留 H6 的局部期限结构换序，因此 CAGR和Sharpe略高；
- dual12后C5没有近分换序，MDD略浅，但收益下降更多；
- 两者都不如不做 dual12 过滤的原 H6。

这与前序 F1 结论一致：H6在过滤后的子集里仍有 `+0.065` Sharpe的局部增量，但过滤
本身损害过大。

## 最终建议

```text
优先级1：H6 + 宽商品BM5+dual12 50/50（跨载体，影子研究）
优先级2：单独H6
优先级3：若必须ETF同载体，选H6+dual12后H6作收益优先研究
不推荐：H6+dual12后C5作为主要配置
```

但需强调：H6与宽商品组合跨执行载体，必须先建立统一保证金、资金流和成本账本；
同载体的两个选项虽然更容易执行，但历史分散化不足，不能因为最终净值高于单独Blend B
就误判为增强。
