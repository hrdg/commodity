# AW7 R3 扩展：双动量先过滤

日期：2026-11-23
状态：`DUAL_FILTER_VIEWED_HISTORY_NOT_OOS`

## 直接回答

**部分净值会更好，但没有得到稳健、可生产确认。**

最明显的改善是：

```text
12个月绝对动量>0 + 相对动量前50%
  -> 在合格集合内按BM5选 top third
  -> lag1执行
```

该组合 5bp CAGR `17.09%`、Sharpe `0.8669`、MDD `-20.57%`；
未过滤 BM5 lag1 为 `10.50% / 0.6979 / -20.78%`。净值和夏普明显更高，20.5bp
Sharpe 也从 `0.6273` 升到 `0.7986`。

但这个结果不能直接采用：

- 5bp Sharpe差的 95% bootstrap 区间为 `[-0.213,+0.569]`，BH q=`0.658`；
- 同收盘 paper-like 口径只有 `0.7125`，相对未过滤 BM5 `0.6965` 仅增加 `0.016`；
- 过滤后平均敞口 `96.9%`，并非完全由空仓解释，但只有4个现金月；
- 所有历史已看，数据无 vintage，且没有独立 OOS。

因此结论是：**双动量在 12 个月窗口下能让 BM5 的历史净值更好，尤其在滞后执行口径；
但证据不足以把它认定为稳定 alpha 或生产升级。**

## 关键发现

1. **6个月双动量不适合多头。** `BM5+dual6` 在 paper-like 的 MDD 恶化到
   `-36.83%`，lag1 Sharpe 只有 `0.254`。多数产品的6个月负动量是三季度反转/极端
   回撤后的状态，过滤会错过反弹。
2. **12个月双动量对 BM5 有选择性帮助。** 它避免了少数12个月趋势差、但当时 BM5
   排名高的产品；但结果对执行滞后很敏感，说明时点与样本路径仍可能主导。
3. **不能把同一过滤套在 Carry 或 MOM12 上。** 两者过滤后 MDD明显恶化、Sharpe下降。
4. **dual6 的 EW 组合略有 Sharpe 改善，但高成本和 lag1均失败**，不能作为稳定
   防御层。

## 机制解释

12个月绝对动量过滤剔除了长期下跌商品，BM5/Carry 则在剩余商品中排序；这个顺序符合
“趋势先保命、期限结构再选品”的直觉。竞争解释是：

- 相同股票/商品 beta 暴露仍在，只是过滤后组合更集中；
- 4个现金月降低了平均敞口；
- lag1 的结果可能包含特定年份的反弹路径；
- 12个月窗口是既有项目中的既定双动量窗口，并非本轮搜索所得，但仍是历史选择。

## 裁决

| 假设 | 状态 | 处置 |
|---|---|---|
| 双动量过滤所有 R3 净值 | `PARTIAL` | 只有 BM5+dual12 明显改善，EW/Carry/MOM多数变差 |
| BM5+dual6 | `REJECT` | paper-like 和 lag1 均不稳，滞后回撤大幅恶化 |
| BM5+dual12 | `SHADOW_ONLY` | 历史净值候选，bootstrap不显著，禁止生产替换 |
| 继续搜索 18/24个月或40/60%阈值 | `STOP` | 不在已见样本继续窗口/阈值搜索 |

## 下一步

若继续，唯一值得保留的是 `BM5 + dual12` 的**前瞻影子**，而不是直接上线：

- 冻结绝对阈值0、相对分界50%、12个月窗口；
- 记录每月过滤后候选数、现金月、BM5目标、平均敞口；
- 在同一未来月份上同时运行未过滤BM5；
- 至少经历完整的商品趋势反转周期后再评估。
